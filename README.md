# BKM Mannesmann Design System

Dieses Repository enthält das offizielle Design System der BKM Mannesmann AG, basierend auf den Corporate Design Richtlinien (V2.8, März 2026).

## Struktur

- `DESIGN.md`: Die maschinenlesbare (und menschenlesbare) Definition des Design Systems, optimiert für AI-Coding-Agenten (inspiriert durch das [awesome-design-md](https://github.com/VoltAgent/awesome-design-md) Konzept).
- `docs/`: Ausführliche Dokumentation zu spezifischen Anwendungsbereichen.

## Verwendung mit AI-Agenten

Die Datei `DESIGN.md` im Hauptverzeichnis ist so strukturiert, dass sie direkt von AI-Agenten (wie Cursor, GitHub Copilot, oder autonomen Agenten) gelesen werden kann, um UI-Komponenten und Layouts zu generieren, die exakt dem BKM Mannesmann Corporate Design entsprechen.

Weisen Sie Ihren Agenten einfach an:
> "Lies die DESIGN.md und erstelle eine Landingpage im BKM Mannesmann Design."

## Kernprinzipien

Das BKM Design System basiert auf folgenden Säulen:
1. **Farben**: Deep Green und Pure Green als Basis, Lime Green als Signalfarbe für Lösungen und CTAs.
2. **Typografie**: Unbounded Black (Versalien) für markante Headlines, TT Norms Pro für exzellente Lesbarkeit im Fließtext.
3. **Keyvisual**: Das dynamische Chevron-Muster, das den Aufbau von Schutz symbolisiert.
4. **Tonalität**: Kompetent, nahbar und motivierend.
