# Icon-System

Das BKM Mannesmann Icon-System folgt einem einheitlichen visuellen Prinzip, das Konsistenz und sofortige Wiedererkennbarkeit gewährleistet.

## Spezifikationen

| Merkmal | Spezifikation |
|---------|--------------|
| Form | Kreisförmig |
| Hintergrund | Deep Green (`#1c4b42`) |
| Symbol | Linien-Icon in Lime Green (`#b4e717`) |
| Stil | Flat Design, minimalistisch, konsistente Linienstärke |
| Format | SVG (skalierbar) |

## Gestaltungsprinzipien

Alle Icons im BKM System teilen folgende Eigenschaften:

| Prinzip | Umsetzung |
|---------|-----------|
| Einheitliche Form | Immer kreisförmig, keine Ausnahmen |
| Farbkonsistenz | Lime Green Linien auf Deep Green Hintergrund |
| Linienstärke | Identisch über alle Icons hinweg |
| Verständlichkeit | Einfach und international verständlich |
| Skalierbarkeit | SVG-Format für verlustfreie Skalierung |

## Erstellung neuer Icons

Neue Icons müssen folgende Kriterien erfüllen:

1. **Kreisförmiger Hintergrund** in Deep Green (`#1c4b42`)
2. **Lime Green Symbol** (`#b4e717`) als Linien-Icon
3. **Gleiche Strichstärke** wie bestehende Icons im System
4. **Einfache, klare Symbolik** die international verständlich ist
5. **SVG-Format** für Web- und Print-Anwendungen
