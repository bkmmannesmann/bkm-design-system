# Logo

Das BKM Mannesmann Logo besteht aus zwei Bestandteilen: der **Wortmarke** (zweizeiliger Schriftzug "BKM" / "MANNESMANN") und dem **Signet** (pfeilartiges Doppel-M-Symbol rechts, abgeleitet vom Keyvisual).

## Varianten

| Variante | Schriftzug | Signet | Verwendung |
|----------|-----------|--------|------------|
| **Primärlogo** | Stone Grey | Pure Green | Standard auf hellen Hintergründen (Weiß, Sand White) |
| **Sekundärlogo** | Clean White | Pure Green | Auf dunklen, einfarbigen Hintergründen (Deep Green) |
| **Negativlogo** | Clean White | Clean White | Auf dunklen Bildhintergründen ohne ausreichenden Kontrast |

## Schutzraum und Mindestgröße

| Parameter | Digital | Print |
|-----------|---------|-------|
| Mindestbreite | 120 px | 25 mm |
| Schutzraum | Versalhöhe des BKM-Schriftzugs im Logo auf allen vier Seiten |

Der Schutzraum wird definiert durch die Versalhöhe (Cap Height) des "BKM"-Schriftzugs im Logo. Dieser Abstand muss auf allen vier Seiten um das Logo herum freigehalten werden.

## Positionierung auf Printmedien

Das Logo wird auf allen Printmedien **links oben** positioniert. Die universelle Maßeinheit für den Mindestabstand ist die **Versalhöhe des BKM-Schriftzugs im Logo**:

| Abstand | Maß |
|---------|-----|
| Abstand oben | 1x Versalhöhe |
| Abstand links | 1x Versalhöhe |

Dieses selbstreferenzierende System skaliert automatisch mit der Logo-Größe.

**Ausnahme**: Auf **Titelblättern und Postern** darf das Logo individuell ausgerichtet werden, angepasst an die jeweilige Komposition und das Gesamtlayout.

## Falschanwendungen (verboten)

Folgende Anwendungen des Logos sind strikt untersagt:

| Verboten | Begründung |
|----------|-----------|
| Farben verändern | Markenidentität wird verwässert |
| Proportionen verzerren | Qualitätseindruck leidet |
| Elemente entfernen/trennen | Logo ist eine Einheit |
| Konturen/Schatten/Effekte | Widerspricht dem Clean-Design-Ansatz |
| Auf unruhige Hintergründe setzen | Lesbarkeit und Wirkung gehen verloren |
