# MicroPorex und Technische Richtlinien

## MicroPorex Technologie-Marke

MicroPorex ist die offizielle Ingredient Brand der BKM Mannesmann AG, vergleichbar mit "Intel Inside" oder "Gore-Tex". Sie signalisiert: "Dieses Produkt enthält unsere fortschrittlichste Technologie."

### Der BKM Moment

MicroPorex beschreibt den Moment, in dem die Produkte auf molekularer Ebene in das Mauerwerk eindringen und einen unsichtbaren, dauerhaften Schutzschild aufbauen.

### 3-Phasen-Wirkung

| Phase | Beschreibung |
|-------|-------------|
| 1. Eindringen | Aktive Wirkstoffe dringen tief in die Poren des Baustoffs ein |
| 2. Reagieren | Chemische Reaktion mit dem Untergrund bildet eine Schutzschicht |
| 3. Schützen | Dauerhafter Schutzschild gegen Feuchtigkeit und Schäden |

### Logo-Varianten

| Variante | Verwendung |

| Lime Green auf Dunkel | Primärvariante auf Deep Green oder True Black Hintergründen |
| Schwarz auf Hell | Sekundärvariante auf Sand White oder Clean White Hintergründen |

### Anwendungsregeln

- Immer in Verbindung mit dem BKM Logo verwenden
- Claim "Powered by BKM Mannesmann" ergänzen
- Als Siegel auf Produkten, Verpackungen und in der Kommunikation
- Schutzraum einhalten

## Technische Richtlinien

### Dateiformate

| Anwendung | Format | Hinweis |
|-----------|--------|---------|
| Logo (Vektor) | SVG, EPS, AI | Für alle skalierbaren Anwendungen |
| Logo (Pixel) | PNG (transparent) | Wenn keine Vektorgrafiken unterstützt werden |
| Bilder (Web) | WebP, JPEG | WebP bevorzugt für optimale Ladezeiten |
| Bilder (Print) | TIFF, JPEG | Mindestauflösung 300 dpi |
| Icons | SVG | Skalierbar und für Web optimiert |
| Druckvorlagen | PDF/X-4 | Für die Druckproduktion |

### Naming Convention

Muster: `[Typ]_[Nummer]_[Produktname]_[Details]_[Sprache].[Format]`

| Block | Beschreibung | Beispiele |
|-------|-------------|-----------|
| [Typ] | Art des Assets | Produktbild, VA, TDS, Listing_Image, Etikett |
| [Nummer] | Dreistellig, fortlaufend | 001, 002, 003 |
| [Produktname] | Produktbezeichnung | BKM_HDS-2K_Pro, NovuTop |
| [Details] | Gebinde, Variante (optional) | 25L, 10kg, Eimer, Gruppe |
| [Sprache] | ISO 639-1 | DE, EN, FR |

Beispiele: `Produktbild_001_BKM_HDS-2K_Pro_25L_DE.tif`, `VA_001_BKM_HDS-2K_Pro_DE.pdf`
