# Logo Variants

This directory will contain the official BKM Mannesmann logo SVGs.

## Planned Variants

| File | Context | Description |
|------|---------|-------------|
| `bkm-logo-on-light.svg` | BKM AG | Deep Green wordmark + Deep Green claim on white/sand |
| `bkm-logo-on-dark.svg` | BKM AG | White wordmark + White claim on Deep Green/dark |
| `bkm-logo-on-deep-green.svg` | BKM AG | White wordmark + Lime claim on Deep Green |
| `bkm-logo-fachbetrieb-on-light.svg` | Fachbetrieb | Stone Grey wordmark + Transition Green claim on white/sand |
| `bkm-logo-black.svg` | Reserve/Print | Full black for single-color print |

## Export Rules

All logos must be exported from Adobe Illustrator with:
- **CSS-Eigenschaften**: Präsentationsattribute
- **Responsiv**: deaktiviert
- **Dezimalstellen**: 2
