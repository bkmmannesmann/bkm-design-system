## 1. Visual Theme & Atmosphere

BKM Mannesmann's design system is the visual embodiment of "Schutz" (protection) made tangible — a dual-mode architecture that alternates between massive deep-green marketing surfaces and clean sand-white documentation canvases. The system is unapologetically industrial: angular geometries for the professional tier, zero-radius buttons that communicate engineering precision, and a single accent color (Lime Green `#b4e717`) that is reserved exclusively for interactive elements — never decorative, never ambient, always a call to action.

The custom display face Unbounded Black at 900 weight with aggressive negative letter-spacing (-2.5px at hero sizes) creates headlines that feel compressed and engineered — like a product label stamped onto concrete. At body sizes, Inter takes over with relaxed line-heights (1.6–1.7) for maximum readability in technical documentation. Geist Mono serves as the "specification voice" — used for article numbers, measurements, pH values, and technical data that connects marketing to the physical product.

What distinguishes BKM from other green-branded systems is the **shadow-as-border philosophy** (adapted from Vercel's approach). Instead of traditional CSS borders, BKM uses multi-layer shadow stacks where each layer serves a specific architectural purpose: one creates the "border" (0px spread, 1px), another adds ambient softness (2–4px blur), and an optional inner ring creates the subtle highlight that makes cards feel "built, not floating." This technique allows borders to exist in the shadow layer, enabling smoother hover transitions and a more premium feel.

The **chevron pattern** — a layered V-shape motif — is the signature decorative element. It appears at 10–15% opacity as a background texture on hero bands, as a CSS clip-path on section dividers, and as a small corner-mark on featured cards. It represents the core brand promise: layered protection against moisture.

**Key Characteristics:**
- Unbounded Black 900 with extreme negative letter-spacing (-2.5px at 64px, -1.5px at 48px, -1px at 36px) — text as stamped infrastructure
- Inter 400/500/700 for body copy with generous line-heights (1.6–1.7) — optimized for technical reading
- Geist Mono for specifications, article numbers, and technical values — the "data voice"
- Shadow-as-border technique: multi-layer `box-shadow` stacks replace traditional borders
- Dual-mode surfaces: Deep Green (`#1c4b42`) for marketing, Sand White (`#f6f5f2`) for documentation
- Single-accent strategy: Lime Green (`#b4e717`) exclusively for CTAs and interactive states
- Product-line geometry: 0–4px radius for Pro Line (angular/technical), 9999px for Home Line (pill/accessible)
- Chevron motif at 10–15% opacity as background texture on dark surfaces
- Focus ring system using double-ring technique: white inner + green outer for accessibility

## 2. Color Palette & Roles

### Brand Greens (Primary Palette)
- **Deep Green** (`{colors.brand-deep-green}` — `#1c4b42`): Hero backgrounds, navigation, footer, dark surfaces, Pro Line primary. The anchor of the system — represents depth, expertise, permanence.
- **Transition Green** (`{colors.brand-transition-green}` — `#287d4b`): Hover states on Deep Green elements, gradient midpoint, secondary dark surface.
- **Pure Green** (`{colors.brand-pure-green}` — `#4daf46`): Home Line primary, secondary buttons, success states, specialist company (Fachbetrieb) branding. Warmer and more accessible than Deep Green.
- **Lime Green** (`{colors.brand-lime}` — `#b4e717`): The single accent. CTAs, active states, checkmarks, interactive icons on dark backgrounds. Never used for text, never for backgrounds, never decorative.
- **Lime Soft** (`{colors.brand-lime-soft}` — `#d4f07a`): Hover state for Lime Green buttons (lighter variant).
- **Lime Muted** (`{colors.brand-lime-muted}` — `#e8f5b3`): Subtle highlight backgrounds for callout boxes on light surfaces.

## 3. Typography Rules

### Font Family
- **Display**: `Unbounded` weight 900 (Black) — the brand display face. Geometric, compressed, industrial. Used exclusively for headlines and button labels. Falls back to `system-ui, sans-serif`.
- **Body**: `Inter` weights 400/500/700 — the reading face. Optimized for screen readability at all sizes. Falls back to `system-ui, -apple-system, sans-serif`.
- **Mono**: `Geist Mono` weight 400/500 — the specification face. Used for technical data, article numbers, code, measurements. Falls back to `Source Code Pro, ui-monospace, monospace`.

### Principles
- **Compression as authority**: Unbounded at display sizes uses aggressive negative tracking (-2.5px at 64px). This creates text that feels stamped, permanent, engineered — like product labels on industrial packaging. The tracking progressively relaxes: -1.5px at 48px, -1px at 36px, -0.5px at 28px, 0 at 22px and below.
- **Three faces, strict roles**: Unbounded for announcements (headlines, buttons), Inter for reading (body, descriptions), Geist Mono for data (specs, codes, measurements). Never mix roles.
- **Weight discipline**: Unbounded only at 900. Inter at 400 (read), 500 (interact), 700 (emphasize). Geist Mono at 400 (display) and 500 (labels).
- **Uppercase for authority**: All Unbounded text is uppercase. This is non-negotiable — it's the brand voice in typographic form.
- **Line-height for comfort**: Body text uses generous line-heights (1.6–1.7) because technical content requires breathing room. Headlines are tight (1.05–1.25) for visual impact.

### Font Substitutes
Unbounded is available via Google Fonts. The closest alternative is **Archivo Black** (weight 900, geometric, compressed). Inter is the default — no substitution needed. Geist Mono is available via Google Fonts; fallback to **Source Code Pro** or **JetBrains Mono**.

## 5. Layout Principles

### Spacing System
- Base unit: 4px
- Scale: 4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px, 96px, 120px
- Component internal: `{spacing.sm}` to `{spacing.lg}` (12–24px)
- Between components: `{spacing.xl}` to `{spacing.xxl}` (32–48px)
- Between sections: `{spacing.section}` to `{spacing.section-lg}` (64–96px)
- Hero padding: `{spacing.hero}` (120px)

### Grid & Container
- Max content width: 1280px
- Container padding: 16px (mobile) → 24px (tablet) → 32px (desktop)
- Hero: asymmetric split — 60% copy / 40% imagery (desktop), stacked (mobile)
- Feature sections: 2–3 column grids with `{spacing.lg}` (24px) gap
- Documentation: 3-column layout — sidebar (240px) + content (1fr) + TOC (200px)
- Full-width sections: edge-to-edge dark bands with contained content

### Whitespace Philosophy
- **Dual-mode breathing**: Marketing surfaces (dark) use massive vertical padding (96–120px) to create drama and authority. Documentation surfaces (light) use tighter padding (48–64px) for information density.
- **Asymmetric heroes**: Hero copy never centers. It hugs the left 60% of the viewport, leaving the right for imagery or decorative chevron patterns. This creates directional energy.
- **Section rhythm**: Dark bands alternate with light bands. The contrast between Deep Green and Sand White IS the section separator — no additional borders or dividers needed.
- **Card breathing**: Cards have generous internal padding (`{spacing.xl}` minimum) and generous external gaps (`{spacing.lg}` between cards). Content never feels cramped.

### Border Radius Scale
- **None** (0px): Pro Line buttons, dark info boxes — angular, technical, no-nonsense
- **XS** (2px): Pro Line badges, small angular elements — barely rounded
- **SM** (4px): Pro Line cards, code containers — subtle softening
- **MD** (8px): Inputs, alerts, standard containers — comfortable
- **LG** (12px): Standard cards, featured containers — friendly
- **XL** (16px): Large featured cards, hero images — generous
- **XXL** (24px): Modal containers, large panels — very rounded
- **Full** (9999px): Home Line buttons, Home Line badges, pill tabs — fully rounded

### Product Line Geometry Rules
- **Pro Line**: radius 0–4px. Angular. Technical. Serious. Represents professional expertise.
- **Home Line**: radius 8–9999px. Rounded. Accessible. Friendly. Represents DIY approachability.
- **Mixed contexts**: Use `{rounded.lg}` (12px) as the neutral default when both lines appear together.

## 6. Depth & Elevation

| Level | Token | Treatment | Use |
|---|---|---|---|
| Flat (Level 0) | — | No shadow | Page background, text blocks, dark surfaces |
| Ring (Level 1) | `{shadows.ring}` | `rgba(0,0,0,0.08) 0px 0px 0px 1px` | Shadow-as-border for inputs, subtle containers |
| Subtle (Level 2) | `{shadows.subtle}` | Ring + `rgba(0,0,0,0.04) 0px 2px 4px` | Standard cards, default elevation |
| Card (Level 3) | `{shadows.card}` | Ring + `rgba(0,0,0,0.04) 0px 4px 8px` | Emphasized cards, testimonials |
| Featured (Level 4) | `{shadows.featured}` | Ring + `rgba(0,0,0,0.06) 0px 8px 16px -4px` + inner white ring | Featured cards, hover states, highlighted panels |
| Elevated (Level 5) | `{shadows.elevated}` | Ring + `rgba(0,0,0,0.08) 0px 12px 24px -8px` | Modals, dropdowns, popovers |
| Focus | `{shadows.focus}` | `0 0 0 2px #ffffff, 0 0 0 4px #4daf46` | Keyboard focus on light surfaces |
| Focus Dark | `{shadows.focus-dark}` | `0 0 0 2px #1c4b42, 0 0 0 4px #b4e717` | Keyboard focus on dark surfaces |

**Shadow Philosophy**: BKM uses the Vercel-inspired multi-layer shadow approach where each layer has a distinct purpose. The "ring" layer (0px spread, 1px) creates a border-like outline without box model implications. The "elevation" layer (2–16px blur) adds depth perception. The "inner ring" (white inset on featured cards) creates a subtle inner glow that makes cards feel solid and built. On dark surfaces, shadows are unnecessary — depth comes from background color variation (`{colors.surface-dark}` vs `{colors.surface-dark-elevated}`).

## 7. Animation & Motion

### Timing
- **Fast** (150ms): Button press, toggle, checkbox state change
- **Normal** (200ms): Hover transitions, color changes, shadow transitions
- **Slow** (300ms): Accordion open/close, dropdown reveal
- **Entrance** (500ms): Section fade-in on scroll, page transitions

### Easing
- **Default** (`cubic-bezier(0.4, 0, 0.2, 1)`): Standard transitions
- **Entrance** (`cubic-bezier(0, 0, 0.2, 1)`): Elements entering the viewport
- **Exit** (`cubic-bezier(0.4, 0, 1, 1)`): Elements leaving the viewport
- **Spring** (`cubic-bezier(0.34, 1.56, 0.64, 1)`): Playful micro-interactions (Home Line)

### Patterns
- **Scroll reveal**: Sections fade in + slide up (24px) with 100ms stagger between children
- **Hover lift**: Cards translate -2px + shadow intensifies to `{shadows.featured}`
- **Button press**: Scale 0.98 on mousedown, return on mouseup
- **Tab switch**: Content fades out (150ms) then fades in (150ms)
- **Accordion**: Height animates with `{animations.easing-default}` over 300ms

### Principles
- Motion is functional, not decorative. Every animation communicates state change.
- Pro Line contexts use shorter durations and linear easing — technical, precise.
- Home Line contexts may use spring easing for a friendlier feel.
- Never animate color on dark surfaces — it creates flicker on Deep Green.
- Scroll-triggered animations fire once (no replay on scroll-up).

## 8. Accessibility

### Focus Management
- All interactive elements have visible focus rings using `{shadows.focus}` (light) or `{shadows.focus-dark}` (dark)
- Focus ring is a double-ring: 2px white inner + 2px green outer — ensures visibility on any background
- Tab order follows visual reading order (left-to-right, top-to-bottom)
- Skip-to-content link as first focusable element

### Color Contrast
- `{colors.ink}` on `{colors.canvas-warm}`: ratio 14.5:1 (AAA)
- `{colors.stone-grey}` on `{colors.canvas-warm}`: ratio 7.2:1 (AAA)
- `{colors.on-dark}` on `{colors.brand-deep-green}`: ratio 12.8:1 (AAA)
- `{colors.brand-lime}` on `{colors.brand-deep-green}`: ratio 6.1:1 (AA Large)
- `{colors.brand-lime}` must NOT be used for body text — only for large labels (18px+) and icons

### Touch Targets
- All buttons: minimum 48px height
- All inputs: minimum 48px height
- Nav links: minimum 44px touch target (via padding)
- Badge/pill taps: minimum 32px height with 44px touch area via padding

### Reduced Motion
- Respect `prefers-reduced-motion: reduce`
- Disable all scroll-triggered animations
- Replace slide/fade with instant opacity change
- Keep focus ring animations (accessibility requirement)

## 11. Do's and Don'ts

### Do
- Use `{colors.brand-lime}` exclusively for interactive elements (CTAs, active states, checkmarks)
- Use shadow-as-border (`{shadows.ring}`) instead of traditional CSS `border` on cards
- Use Unbounded Black 900 uppercase for ALL headlines — no exceptions
- Apply negative letter-spacing that scales with size (-2.5px at 64px, -1.5px at 48px, -1px at 36px)
- Use `{typography.spec-value}` (Geist Mono) for all technical data (measurements, article numbers, pH values)
- Differentiate Pro Line (angular, 0–4px radius) from Home Line (rounded, pill-shaped)
- Use the chevron pattern at 10–15% opacity only — never as a primary visual element
- Pair dark hero bands with light documentation sections for rhythm
- Use `{shadows.focus}` double-ring for all keyboard focus states
- Keep body text in `{colors.stone-grey}` on light surfaces — never pure black

### Don't
- Don't use `{colors.brand-lime}` for body text, backgrounds, or decorative elements
- Don't use `{colors.brand-lime}` on light backgrounds as text (contrast fails below 18px)
- Don't apply `{rounded.full}` (pill) to Pro Line elements — pills are Home Line only
- Don't apply `{rounded.none}` (angular) to Home Line elements — angular is Pro Line only
- Don't use traditional CSS `border` on cards — use the shadow-as-border system
- Don't mix Unbounded with lowercase — it's always uppercase
- Don't use Inter for headlines or buttons — Unbounded only
- Don't use more than one Lime Green CTA per viewport fold — it dilutes the signal
- Don't introduce additional accent colors (no orange, no purple, no blue for decoration)
- Don't center hero copy — it's always left-aligned with asymmetric layout
- Don't use heavy shadows (> 0.1 opacity) — the shadow system is subtle
- Don't animate colors on dark surfaces — it creates flicker
- Don't skip the inner white ring in `{shadows.featured}` — it's the glow that makes cards feel solid

8. The inner white ring in `{shadows.featured}` is what gives cards their premium feel
9. Chevron pattern: 10–15% opacity, never more — it's atmosphere, not content
10. One Lime CTA per fold maximum — scarcity creates urgency
