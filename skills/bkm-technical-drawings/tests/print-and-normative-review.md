# Print, PDF and Normative Review

## Print and PDF

Die Zeichnung wird auf dem vorgesehenen Papierformat bei 100 % geprüft. Dabei müssen Linienstärken, Materialmuster, Mikrotexte, Terminatoren, Callouts, Blattgrenzen und die Vektoreigenschaft der PDF-Ausgabe bewertet werden. Browseransicht allein ist kein ausreichender Drucktest.

## Normative Review

Die Registry kann Quellen, Ausgaben, Status und betroffene Komponenten dokumentieren. Sie kann weder die Anwendbarkeit im konkreten Bauvorhaben bestimmen noch eine normative Konformität freigeben.

| Prüfpflicht | Erwartetes Ergebnis |
|---|---|
| Quelle und Ausgabe | Mit lizenzierter Primärquelle und Datum geprüft. |
| Anwendbarkeit | Für genau dieses Detail und das konkrete Projekt dokumentiert. |
| Aussage in der Zeichnung | Keine unbelegte normative Behauptung. |
| Offene Punkte | Mit `NORMATIVE_VERIFICATION_REQUIRED` sichtbar markiert. |
| Freigabe | Nur durch benannte, menschliche Fachverantwortung. |
