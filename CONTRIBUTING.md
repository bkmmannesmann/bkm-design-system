# Beitragen zum BKM Design System

Vielen Dank für dein Interesse, zum BKM Mannesmann Design System beizutragen!

## Regeln

1. **CD-Konformität**: Alle Änderungen müssen den Corporate Design Richtlinien (V2.8) entsprechen.
2. **Freigabe**: Änderungen an Farben, Typografie oder Logo-Richtlinien erfordern die Freigabe durch das BKM Marketing-Team.
3. **Versionierung**: Jede Änderung muss im Changelog dokumentiert werden.

## Prozess

1. Erstelle einen Branch mit dem Muster `feature/beschreibung` oder `fix/beschreibung`.
2. Nimm deine Änderungen vor.
3. Erstelle einen Pull Request mit einer klaren Beschreibung der Änderung.
4. Warte auf Review und Freigabe.

## Fragen?

Wende dich an das Marketing-Team der BKM Mannesmann AG.
